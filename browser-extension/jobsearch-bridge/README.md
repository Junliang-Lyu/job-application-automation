# Job Search 本地搜岗连接

首次安装（在 Job Search 配置窗口中）：
1. 打开 edge://extensions，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择本文件所在文件夹。
3. 在这个窗口打开 http://127.0.0.1:8765/ 并刷新。
4. 自动搜岗区域应显示“Job Search 扩展已连接”，然后点开始搜岗。

权限仅限 localhost 工作台及 LinkedIn、SMU Handshake 页面内容；无 cookies、密码、浏览历史读取权限。扩展只打开/关闭自己创建的标签，不操作用户的投递表单、不提交申请，不复制登录资料。保持工作台标签打开，关闭会使本轮结果无法回传。

LinkedIn：按工作台关键词和地区搜岗，每查询最多两份完整 JD。
Handshake：当前只读取登录后当前列表，关键词/地区筛选尚未适配；无法提取完整 JD 就报告阻塞，不用整页文本假装 JD。

后端仍负责去重、DeepSeek 分析、材料；扩展不持有 API key。支持范围内的真实站点解析仍需安装后的实测。不会自动识别投递成功，本扩展当前只解决 Job Search 会话搜岗连接。
